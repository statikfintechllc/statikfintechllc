# Server Domain Component Cache

Artifacts in this folder are generated by `./build/build.sh` for the secure server portal. They inherit behaviour from the global component set and apply theme variables sourced from `src/server/server.styles/`.

Use the manifest command to refresh everything:

```bash
./build/build.sh component-manifest --manifest src/build/components.manifest.json --clean
```

Treat the `desktop/` and `mobile/` directories as build outputs only; they are wiped and regenerated on each manifest run.
