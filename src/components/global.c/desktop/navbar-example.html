SFTi Navbar Component – Desktop Variant

Usage Instructions

1. Include the Component

<script src="components/global.c/desktop/navbar.js"></script>

2. Add Container

<div id="navbar-container"></div>

3. Initialize

// For main domain
createSFTiNavbar(SFTiNavbarConfigs.main);

// For dev domain
createSFTiNavbar(SFTiNavbarConfigs.dev);

// For server domain
createSFTiNavbar(SFTiNavbarConfigs.server);

// Custom configuration
createSFTiNavbar({
    logoText: 'Custom',
    logoSubtitle: 'Your Subtitle',
    items: [
        { title: 'Home', href: '#home' },
        { title: 'About', href: '#about' }
    ]
});

Features

  • Fixed 48px height (h-12) for consistent desktop layout
  • Responsive behaviour with slide-out mobile menu fallback
  • Tailwind CSS utility classes for rapid customization
  • Brand colour accent hooks for each domain
  • Configurable link set with external link handling

CSS Requirements

Ensure the body accounts for the fixed navbar height:

<body class="pt-12">
