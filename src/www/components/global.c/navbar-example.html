SFTi Navbar Component

Usage Instructions

1. Include the Component

<script src="components/navbar.js"></script>

2. Add Container

<div id="navbar-container"></div>

3. Initialize

// For main domain
createSFTiNavbar(SFTiNavbarConfigs.main);

// For dev domain  
createSFTiNavbar(SFTiNavbarConfigs.dev);

// For server domain
createSFTiNavbar(SFTiNavbarConfigs.server);

// Custom configuration
createSFTiNavbar({
    logoText: 'Custom',
    logoSubtitle: 'Your Subtitle',
    items: [
        { title: 'Home', href: '#home' },
        { title: 'About', href: '#about' }
    ]
});

Features

  • Fixed 48px height (h-12) - consistent across all browsers
  • Responsive design - desktop nav + mobile hamburger menu
  • Tailwind CSS classes for styling
  • Brand colors: Red for logo, yellow for subtitle
  • Mobile-first approach with slide-out menu
  • Configurable for different domains
  • External link support with proper attributes

CSS Requirements

Add this to your body tag to account for the fixed navbar:

<body class="pt-12">
