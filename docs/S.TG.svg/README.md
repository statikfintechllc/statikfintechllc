## 🚀 Project Overview

**SFTi.Trade_Grade** is a trading grade analysis and scoring system designed to evaluate and rate trading opportunities.

### Core Features
- 📈 **Trade Scoring** - Evaluate trade opportunities
- 📊 **Grade Analysis** - Comprehensive trade grading
- 🎯 **Signal Generation** - Trading signal insights
- 📉 **Risk Assessment** - Risk-adjusted scoring

## 🎨 Card Specifications

- **Theme**: Financial analytics with grade indicators
- **Colors**: SFTi palette with trading accents
- **Dimensions**: 480×230px
- **Format**: SVG
