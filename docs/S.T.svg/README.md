## 🚀 Project Details

**SFTi-TimeLine** provides chronological documentation and project timeline tracking for StatikFinTech initiatives.

### Key Features
- ⏱️ **Timeline Tracking** - Historical project milestones
- 📅 **Event Documentation** - Detailed event records
- 🔄 **Project History** - Complete project lifecycle
- 📊 **Visual Timeline** - Easy-to-follow progress tracking

## 🎨 Card Specifications

- **Theme**: Dark tech with green accents
- **Animations**: Floating particles and glowing borders
- **Colors**: `#00ff88`, `#0088ff`, `#ff0088` 
- **Dimensions**: 480×230px
- **Format**: Animated SVG
