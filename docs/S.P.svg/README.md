## 🚀 Project Details

**SFTi-Pennies** documents trading strategies from Timothy Sykes and Tim Bohen, along with personal trades and notes for a fully transparent trading account.

### Key Features
- 📊 **Trading Strategies** - Documented methodologies from expert traders
- 💹 **Penny Stocks** - Focus on penny stock trading
- 📝 **Transparent Notes** - Detailed trade documentation
- 📈 **Account Tracking** - Full transparency in trading activity

## 🎨 Card Specifications

- **Theme**: Dark tech with green accents
- **Animations**: Floating particles and glowing borders
- **Colors**: `#00ff88`, `#0088ff`, `#ff0088` 
- **Dimensions**: 480×230px
- **Format**: Animated SVG
