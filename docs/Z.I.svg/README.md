## 🚀 Project Overview

**zsh.installer** is an automated zsh configuration and installation system designed to streamline shell setup and configuration.

### Core Features
- 🐚 **Zsh Setup** - Automated zsh installation
- ⚙️ **Configuration** - Pre-configured zsh settings
- 🎨 **Themes** - Custom shell themes
- 🔌 **Plugins** - Essential zsh plugins
